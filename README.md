# Амфодент — прототипы нового сайта

Статические прототипы на реальных данных amfodent.ru (товары, цены, категории, баннеры производителей — без изменений; картинки подгружаются с amfodent.ru).

- `p1-blue/` — вариант 1 «Синий»: главная, каталог с фильтром, карточка товара, корзина, оформление заказа.
- варианты 2–4 — после согласования первого.

Корзина и избранное работают в браузере (localStorage). Формы ничего не отправляют.

## Публикация на GitHub Pages
1. Создать репозиторий, загрузить содержимое этой папки (Add file → Upload files).
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
